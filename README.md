# FitLog

FitLog is a simple workout library website.  
Users can browse workouts, see workout details, save workouts, and add workouts to today's plan.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- LocalStorage

## Features

- View workout list
- View workout details
- Sort workouts by duration, calories, and rating
- Add workouts to today's plan
- Save workouts for later
- Mark workouts as done
- Remove workouts from the plan
- Workout plan data is saved in localStorage
- Responsive design for mobile and desktop

## Project Pages

- Home page
- Workout details page
- My Plan page
- 404 page

## API

Workout data comes from the FitLog API.
